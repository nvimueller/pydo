# pydo

a minimal python cli to-do list application

## install
```bash
pipx install git+https://github.com/nvimueller/pydo.git
```

## commands

`pydo add "<task>"`              add a new task   
`pydo display`                   show all tasks with indexes   
`pydo delete <index>`            mark a task as complete   
`pydo rename <index> "<task>"`   edit a task
